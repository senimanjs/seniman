# Tutorials

Build something real with Seniman through these guided projects. Each tutorial assumes you have completed the [introduction](/docs/introduction) and have a working Seniman application.

## Available tutorials

### Building a Counter

Start with a small interactive application and learn the basic component, state, and event loop.

[Build the counter](/tutorials/building-counter)

### Integrating with SQL

Connect a Seniman application to a SQL database and build a UI whose state is backed by persistent data.

[Integrate with SQL](/tutorials/integrating-with-sql)

### Styling with Tailwind

Use Tailwind CSS with Seniman components while keeping styles close to the markup they describe.

[Style with Tailwind](/tutorials/styling-with-tailwind)
